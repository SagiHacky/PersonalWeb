PyScanner

Nástroj pro průzkum zařízení a dostupných služeb v místní síti. Identifikace operačního systému i výrobce podle MAC adresy je orientační a nemusí být přesná.

PyScanner · Python 3 · Linux

Jazyk
Python 3
Platforma
Linux
Rozhraní
Terminál (CLI)

Projekt slouží k demonstraci základních principů síťového skenování, které využívají nástroje, jako je Nmap. PyScanner je určen pro orientační kontrolu místní sítě a nepředstavuje jeho náhradu.

Co skener zjišťuje

  • Najde místní síť a projde její adresy
  • Zkusí připojení k TCP portům a vypíše dostupné služby
  • Pokusí se přečíst banner služby
  • Odhadne systém podle TTL odpovědi na ping
  • Doplní hostname a dostupnou MAC adresu; výrobce hledá přes online API
  • Vypíše průběh skenování a rozliší otevřené a filtrované porty
  • Skenování lze přerušit pomocí Ctrl+C

Požadavky

  • Python 3.x
  • Linux (používá /proc/net/arp pro získání MAC adresy)
  • Připojení k internetu (vyhledání výrobce přes api.macvendors.com)

Stažení

Zdrojový kód je dostupný na GitHubu a lze jej stáhnout příkazem:

curl -L https://raw.githubusercontent.com/SagiHacky/PyScanner/main/PyScanner.py -o PyScanner.py

Použití

python3 PyScanner.py

Další argumenty nejsou vyžadovány. Skript se pokusí automaticky zjistit rozsah místní sítě a zahájí skenování.

Co skript dělá

  1. Pomocí socket zjistí lokální IP adresu a odvodí rozsah /24
  2. Projde adresy v rozsahu a z pingové odpovědi získá TTL
  3. MAC adresy čte z /proc/net/arp; výrobce dohledává přes api.macvendors.com
  4. Porty zkouší přes TCP sockety; u otevřených se pokusí přečíst bannery
  5. Výsledky vypíše po jednotlivých zařízeních

Omezení

  • Odhad operačního systému podle TTL není spolehlivá identifikace
  • Vyhledání výrobce závisí na dostupnosti bezplatného API
  • Pouze Linux
  • MAC adresa vašeho vlastního zařízení se může zobrazit jako unknown
