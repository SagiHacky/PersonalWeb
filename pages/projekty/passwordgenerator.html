PasswordGenerator

Nástroj příkazové řádky pro generování hesel složených z písmen, číslic a symbolů. Počet i délku hesel lze zadat při spuštění.

PasswordGenerator · Python 3

Jazyk
Python 3
Rozhraní
Terminál (CLI)
Licence
MIT

Skript přijme požadovaný počet a délku hesel a vypíše výsledky do terminálu. V aktuální implementaci převažují číslice, zatímco písmena a symboly se přidávají po stranách. Generátor využívá mimo jiné funkci getrandbits.

Jak to funguje

Skript skládá heslo z číselné části a náhodných znaků, pak výsledek upraví na zadanou délku. Proto v ukázkách číslice převažují:

N}{Oy_1861456763
KU)X/(2065192740
gW.d>$1036343416
_:Ho-/1186353114
|YmZm=1610364937

Při spuštění se zadá požadovaný počet hesel a jejich délka.

Stažení a spuštění

git clone https://github.com/SagiHacky/PasswordGenerator
cd PasswordGenerator
python3 PasswordGenerator.py

Požadován je pouze Python 3; další balíčky není třeba instalovat. Zdrojový kód je dostupný na GitHubu. Samostatný skript lze stáhnout příkazem:

curl -L https://raw.githubusercontent.com/SagiHacky/PasswordGenerator/main/PasswordGenerator.py -o PasswordGenerator.py

Použití

Kolik řádků hesel chceš?
> 10

Jak dlouhé mají být znaky?
> 16

Hesla se vypíšou přímo do terminálu.

Použité znaky

Generátor může použít tyto znaky:

a-z  A-Z  0-9  ! # $ % & ( ) * + , - . / : ; < = > ? @ [ ] ^ _ ` { | } ~

Číslic bývá nejvíc; písmena a symboly se objevují hlavně na okrajích řetězce.
